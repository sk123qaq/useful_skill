# 统计与检验

## 当前定位

这份文档是统计判断的参考，不是“当前 skill 已稳定内建全部这些检验”。

在 `data_analysis_pro` 里，当前较稳定的统计相关能力主要来自 `eda_stats.py`：

- 数值字段描述统计
- 数值/布尔字段相关矩阵
- 在安装 `scipy` 时，对部分数值列做 Shapiro 正态性检验

像 Mann-Whitney、Fisher exact、ADF、Breusch-Pagan、White 这类检验，目前更适合在具体任务里按需写小段 Python 代码，而不是默认假设 skill 已有稳定封装。

## 当前较稳定支持

### 1. 描述统计

适合回答：

- 变量大致分布如何
- 均值、中位数、分位数、缺失率如何

当前来源：

- `eda_stats.py` 的 `summary_statistics`

### 2. 相关性概览

适合回答：

- 数值变量之间是否存在明显线性或单调同向/反向变化线索

当前来源：

- `eda_stats.py` 的 `correlation_matrix`

注意：

- 当前实现本质上是 pandas 的数值相关矩阵，不要把它写成“完整相关分析系统”。

### 3. 正态性提示

适合回答：

- 某些数值列是否明显偏离正态

当前来源：

- `eda_stats.py` 的 `normality_tests`

注意：

- 当前实现只在 `scipy` 可用时运行。
- 默认使用 Shapiro。
- 大样本时它更适合当“分布提示”，不是唯一决策门槛。

## 当前未稳定内建

以下内容可以做，但不要因为 reference 出现过就当成当前 skill 的稳定原子能力：

- 两独立样本均值比较以外的完整双样本检验分流
- Mann-Whitney
- Fisher exact
- Kruskal-Wallis
- ADF
- Breusch-Pagan
- White
- 多重检验校正
- 成体系的因果识别统计检验

如果这些检验对当前任务很关键，建议：

- 在分析上下文里临时写最小代码完成
- 明确写出样本前提、假设条件和限制
- 不要在正式结论里假装它们是 skill 的默认标准流程

## 实用选择框架

### 两组数值比较

- 数据量适中、分布条件基本可接受：
  - 优先用 t 检验思路
- 分布明显偏态、异常值影响重：
  - 考虑非参数方法

但在当前 skill 里，这通常需要单独写检验代码，而不是直接调用现成脚本。

### 多组数值比较

- 如果只是快速判断差异方向：
  - 先看分组描述统计和图
- 如果需要正式显著性判断：
  - 再按数据条件补 ANOVA 或非参数检验

### 比例或列联表比较

- 样本量较大：
  - 可考虑卡方检验
- 稀疏表、期望频数过小：
  - 考虑 Fisher exact

同样，这部分当前不是 `data_analysis_pro` 的稳定脚本能力。

### 时间序列平稳性与异方差

- 如果你的结论严重依赖平稳性、异方差修正、残差诊断：
  - 不要只靠当前 reference 文本
  - 应明确写出你额外执行了哪些检验

## 务必检查

- 样本量是否足够
- 缺失是否会改变样本构成
- 是否存在异常值主导结论
- 观测是否独立
- KPI 是否可加总、可分解
- 你看到的是相关性，还是在尝试主张因果性
- 是否做了很多次检验却只汇报最显著的一次

## 报告中至少应包含

- 检验名称
- 检验对象和分组口径
- 原假设与备择假设
- p 值
- 效应量：若可提供
- 置信区间：若可提供
- 样本量
- 业务解读
- 实际显著性，而不只是统计显著性

## 防护准则

- `p < 0.05` 不等于业务上重要。
- 没做正式检验，不等于不能做分析；但要把措辞降级。
- 正态性检验不过，不代表整个分析无效。
- 只要统计方法不是当前脚本稳定产出，就要在报告里明确“这是本次额外实现”的分析步骤。
