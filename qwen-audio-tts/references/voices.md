# qwen-audio-3.1-tts-next 音色与提示词速查

## 一、音色从哪来（重点）

qwen-audio-3.1-tts-next **没有系统音色 ID，也不支持 `voice` 字段**（传了会 400）。
音色只有两个来源：

1. **提示词描述**（最常用）：在自然语言里描述性别/年龄/嗓音特征，模型据此生成，例如：
   > 一位女性清晰地说：“你好，欢迎使用。”
2. **参考音频**：用 `-r/--reference` 传本地音频（自动转 Base64）或公网 URL，
   最多 3 条，在提示词里按顺序用 `@voice1`、`@voice2`、`@voice3` 引用：
   ```
   python3 scripts/tts.py "@voice1 用开心的语气说：“今天天气真好。”@voice2 在旁边笑。" \
       -r host1.wav -r guest1.wav -o podcast.wav
   ```

参考音频限制（服务端硬限制）：

| 项 | 限制 |
| --- | --- |
| 数量 | 最多 3 条 |
| 单条时长 | ≤ 30 秒（WAV 脚本会自动校验） |
| 单条大小 | ≤ 10 MB |
| 格式 | WAV、MP3、OGG Opus；**不支持裸 PCM** |
| 提交方式 | 公网 URL（`audio_url`）或 Base64 data URI 二选一，不要同时给 |

> 若需要"固定系统音色 ID"（如给定音色反复合成），应改用百炼的语音合成
> （Qwen-TTS/CosyVoice，音色列表见百炼文档"Qwen-TTS音色列表"），本模型不适用。

## 二、提示词写法

公式：**创作任务 + 人物与音色 + 台词（引号）+ 表达方式 + 背景与音效 + 声音变化**

- 台词用引号 `""` 或 `“”` 标出，并注明说话人，如 `旁白：“……”`
- 音色/情绪写角色设定：`（28-30 岁女性，温柔沉静，语速舒缓）`
- 情绪/语气变化直接描述：`语气略微提高，带点惊讶地说`；可标注停顿、笑声、叹气、吞口水
- 背景音效是亮点，写进场景即可：`背景声：窗外细雨轻敲玻璃`
- 保持人物称呼一致；别给同一人物互相冲突的音色/情绪指令
- 支持中文、英文；语种混用也可在描述中写“用英文说”

### 场景示例（可直接改）

**单人旁白**（简洁）
> 一位温柔的女性旁白，语速舒缓地说：“今天的故事，要从一座安静的小城开始。”

**播客（双人）**
> 播客节目，两位主播闲聊。主播1（成年男性，嗓音低沉略带沙哑，语速偏快）平缓地说：“旅行吧，不在于去多远。”主播1语气略微提高，惊讶地说：“那天居然下着小雨！”主播2（年轻女性，嗓音清亮）笑着附和：“我印象也特别深。”

**有声书（多角色）**
> 小说片段多角色配音，场景为初冬咖啡厅，背景声：窗外细雨轻敲玻璃。旁白（28-30岁女性，温柔沉静，语速舒缓）：“初冬的雨下得不大。”角色A宁艺卓（22岁女性，明亮爽利）：“你到底还要犹豫多久？”旁白：“她没有回答。”

**游戏 NPC（带场景音）**
> 游戏NPC台词，场景为村口大树下，背景声：鸡鸣犬吠、风吹树叶。老村长（70岁男性，嗓音苍老、慈祥，语速很慢）叮嘱道：“孩子啊，后山闹起了妖怪，村里人都指望你了。”

**广播剧（情绪+音效）**
> 雨中告白广播剧。男主（27岁，气喘、真挚）：“我找了你整整三条街！我喜欢你！”女主（25岁，声音发颤）：“你……先过来，雨这么大……”背景声：倾盆雨声、偶尔雷鸣。

## 三、一致性 & 时长

- `--seed`（默认 42）：同提示词+同种子≈复现；想要多样就别固定种子。
- 单次生成上限：**播客 240 秒 / 其他场景 120 秒**；提示词上限 3000 字符。
- 超出用 `--split` 按句分块合成再拼接；但注意分块间音色会有轻微模型重采样差异，
  追求统一连贯的长音频，尽量在一个请求的描述内完成。

## 四、快速自检

- `--dry-run` 打印请求体：确认 `references` 数量/顺序、`@voiceN` 编号、format/rate/volume。
- 生成后 `ffprobe <文件>` 看时长、采样率、声道是否与参数一致。
