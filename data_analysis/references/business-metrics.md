# Business Metrics

## Funnel

For ordered funnel steps:

- step count = users reaching the step
- step conversion = current step count / previous step count
- total conversion = current step count / first step count

Always report the largest drop-off and its absolute user count.

## Monetization

- pay rate = paying users / active users
- ARPU = revenue / active users
- ARPPU = revenue / paying users
- repeat purchase rate = repeat buyers / buyers

Check whether revenue is concentrated in a small share of users.

## Retention

- day N retention = users active on day N / users acquired on day 0
- cohort analysis should align acquisition date, not calendar date only

## Cohort

- cohort retention matrix = retained users in period k / cohort size
- choose daily, weekly, or monthly cohorts based on the product usage cycle
- do not compare cohorts with very different acquisition channels without noting mix effects

## LTV

- LTV = total revenue from cohort / users in cohort
- cohort LTV should be compared on the same age basis when cohorts have different lifetimes
- separate pay rate changes from spend-per-payer changes

## Financial Metrics

- return = (ending value - starting value + cash flow) / starting value
- volatility = std of returns
- Sharpe = (mean return - risk free rate) / volatility
- max drawdown = worst peak-to-trough decline
