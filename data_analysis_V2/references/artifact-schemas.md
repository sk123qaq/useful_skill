# Artifact Schemas

The script layer validates these artifacts:
- `analysis_contract`
- `route_decision`
- `feature_risk_report`
- `baseline_results`
- `gate_review`
- `judgment_bundle`
- `claim_registry`
- `judgment_context`
- `agent_decision`

Each artifact must remain machine-readable JSON and should be durable enough for checkpoint resume or post-run audit.
