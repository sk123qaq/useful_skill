# 东财细分行业 → 申万一级行业映射（2021 版 31 类）

用途：东财 `BOARD_NAME` / F10 行业字段约 119 个细分名，直接分 sheet 太碎；按此表聚合到申万一级 31 类再分表，明细里保留细分行业原值。

业已实测：沪市某期末 1093 家覆盖到的 119 个细分行业全部命中本表，零漏映射。新增细分行业未命中时，`SW.get()` 返回 `None` → 汇总成「其他」并把名字打印出来，再补表。

## 易错的几个归类

- 军工电子Ⅱ → **国防军工**，不是电子。
- 焦炭Ⅱ → 煤炭；冶钢原料/特钢Ⅱ → 钢铁；油气开采Ⅱ → 石油石化（不要归入公用事业）。
- 照明设备Ⅱ → 家用电器；饰品 → 纺织服饰；文娱用品 → 轻工制造（不是传媒）。
- 专业服务、教育、酒店餐饮 → 社会服务；数字媒体、游戏Ⅱ、出版、广告营销、影视院线 → 传媒。
- 多元金融、证券Ⅱ、保险Ⅱ → 非银金融；银行Ⅱ 单独一类。
- 其他电源设备Ⅱ、电机Ⅱ → 电力设备；自动化设备、轨交设备Ⅱ → 机械设备。

## Python 用法

```python
sw = SW.get(ind)
if sw is None:
    unmapped.add(ind); sw = '其他'
```

跑完先 `print('未映射行业:', unmapped)`，空集合才往下出表。
